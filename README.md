# Student University System — Frontend Starter

This starter follows the Web roadmap from the repository:

HTML/CSS
→ JavaScript basics
→ TypeScript
→ React
→ Components
→ API calls
→ Authentication
→ Forms/validation
→ Error/loading states

## Run

```bash
npm install
npm run dev
```

## Backend URL

Copy `.env.example` to `.env` and set:

```env
VITE_API_URL=http://localhost:8000
```

The `/auth/login` endpoint is an example contract. Replace it with the exact FastAPI endpoint/response agreed by the backend team.

## Important

This is the frontend foundation. Do not invent university pages or business features until the team provides the actual UI/requirements.
