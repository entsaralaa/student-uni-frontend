# 🎓 Smart University Student Portal

A modern student university portal built with React, TypeScript, and Vite.

## 🚀 Live Demo

👉 https://student-uni-frontend.vercel.app

## ✨ Features

- 🔐 Student Login
- 📊 Student Dashboard
- 📚 My Courses
- 📅 My Schedule
- 🎓 My Grades
- 👤 My Profile
- 🚪 Logout
- 📱 Responsive User Interface

## 🖥️ Dashboard

The dashboard provides students with:

- Total Courses
- Current GPA
- Completed Credits
- Academic Status
- Student Information
- Academic Summary

## 🛠️ Technologies

- React
- TypeScript
- Vite
- CSS
- Git & GitHub
- Vercel

## 🎯 Project Purpose

The project is a frontend implementation of a Smart University Student Portal.

It provides students with a simple interface to access their academic information.

> Note: This is a frontend/demo project. Authentication and academic data are currently simulated on the frontend.
